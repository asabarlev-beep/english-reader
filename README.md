# קריאה באנגלית

אפליקציה לקריאת ספרים מלאים באנגלית, עם תרגום לעברית בלחיצה על מילה, שמירת מילים, כרטיסיות חזרה וכתיבה.
עובדת גם בלי אינטרנט: האפליקציה, המילון והספרים שבחרת לשמור נשמרים בטלפון.

- `app/` – האפליקציה (HTML אחד + service worker)
- `scripts/build_data.py` – מוריד את הספרים מפרויקט גוטנברג ובונה מילון אנגלית-עברית מוויקימילון (kaikki.org)
- `.github/workflows/deploy.yml` – בונה ומפרסם ל-GitHub Pages בכל עדכון

להוספת ספר: הוסף את המספר שלו בגוטנברג לרשימה `BOOKS` בקובץ `scripts/build_data.py`.
רמות: 1=קל 2=בינוני 3=מתקדם 4=מומחה. השנה (year) קובעת אם הספר מופיע גם בסינון "מודרני" (1920 ואילך).
